# 第 102 章 命令速查表

本章按「你在做什么」分组，而不是按字母序排列。每条只给最常用的形式；参数细节以 `man` 与 Wiki 为准，所属章节在备注列。带 **危险** 的命令执行前必须先确认对象，确认方法见本章末的「危险命令确认清单」。

> 本章目标：在不离开书的情况下查到正确命令；知道每条命令属于哪一章的知识点；对破坏性命令形成固定的确认习惯。
> 对应 Wiki：[Core utilities](https://wiki.archlinux.org/title/Core_utilities)｜[Pacman](https://wiki.archlinux.org/title/Pacman)｜[Systemd](https://wiki.archlinux.org/title/Systemd)

## 读表约定

- `设备` 指 `/dev/...`，`挂载点` 指 `/mnt/...` 一类目录；模板值要替换成你自己的值。
- 「章」列是知识点出处，不是命令的手册页。
- 标注 **危险** 的命令会改写块设备、删除数据或改变启动行为；先读本章末的确认清单。
- 同一个目的有多种做法时，只列本书推荐的那一种，其余在对应章讲取舍。

## 危险命令确认清单

| 命令族 | 会改什么 | 执行前必须 |
| ---------------------------------- | ------------------------ | ------------------------------------------------------ |
| `rm -rf` | 删除目录树 | `ls` 同一路径；变量加 `${VAR:?}` 空值防护 |
| `fdisk` / `parted` / `mkfs` | 分区表与文件系统 | `lsblk` 核对设备、容量、挂载点；确认不是宿主盘 |
| `dd` | 按块覆盖设备 | 再核对 `of=` 目标；先用 `status=progress` 小范围试 |
| `pacman -Rns` | 删包与配置 | `pacman -Qi` 看依赖；确认配置不再需要 |
| `pacman -U` 降级 | 包版本回退 | 确认依赖链未升级到不兼容版本 |
| `efibootmgr -o` | 固件启动顺序 | `efibootmgr -v` 先备份顺序；保留一个可启动项 |
| `mkinitcpio -P` | 覆盖全部 initramfs | 确认 `/boot` 有空间；保留旧镜像副本 |
| `virsh snapshot-revert` | 域磁盘回退 | 确认快照时间点；当前数据会丢失 |
| `cryptsetup luksFormat` | 清空并加密设备 | 确认设备为空；抄下 header 备份路径 |

共同结构只有三条：**确认对象、先备份、留一条退路**。这三条固定下来，比背命令更有效。

## 小结

- 查命令按「你在做什么」分组：文件、进程存储网络、安装引导、pacman 打包、维护排障、服务运维、安全、桌面。
- pacman 的查询类命令是排障基础；破坏性命令集中在 `-Rns`、`-U`、`-Sy`。
- systemd 的 `enable` 与 `start` 独立，改 unit 后必须 `daemon-reload`。
- 磁盘类命令执行前必须 `lsblk`；`genfstab` 只执行一次。
- 危险命令的确认清单只有三条：确认对象、先备份、留退路。
- 桌面类命令依赖图形会话环境变量；远程执行先确认 `DISPLAY` 与 `WAYLAND_DISPLAY`。

## 练习

1. 用本表查出 `/usr/bin/bash` 属于哪个包，并列出该包的全部文件。
2. 分别用 `systemctl status` 与 `journalctl -u` 查看同一个服务的状态与日志，说明两者信息差。
3. 用 `lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS` 找出虚拟机磁盘的设备名、分区与挂载点。
4. 在虚拟机里执行一次 `fdisk -l`，指出哪个设备是 ESP，并说明判断依据。
5. 用 `virsh snapshot-create-as` 建快照、`snapshot-list` 查看、`snapshot-revert` 回滚，确认系统回到快照时刻。
6. 从「危险命令确认清单」挑三条，写出你在自己机器上的具体确认步骤。
7. 用 `grep -c '^- \[第' src/SUMMARY.md` 与台账行数命令，核对本书章数与台账规模。
