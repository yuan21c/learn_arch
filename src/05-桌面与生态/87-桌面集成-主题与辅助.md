# 第 87 章 桌面集成、主题与辅助

桌面「装好了」和「用起来顺手」是两件事。前者是进程能起来，后者是**配置放对位置、应用之间共享同一套主题与字体、需要权限时能通过 portal 拿到**。这一章讲 XDG 目录、自启动、GTK/Qt 主题统一、图标与字体、缩放与辅助功能——都是不涉及内核与驱动、却天天影响体验的部分。

> 本章目标：能说出 XDG 五个目录的用途，并判断一份配置该放哪；会用 `~/.config/autostart` 与用户级 systemd 管理自启；能让 GTK 与 Qt 应用使用同一套主题、图标与光标；会用 `fc-cache`/`fc-match` 管理字体；知道 X11 与 Wayland 下缩放的不同做法；能识别「Qt 不跟随 GTK 主题」「自启项不执行」「换主题后图标丢失」三类问题。
> 对应 Wiki：[XDG Base Directory](https://wiki.archlinux.org/title/XDG_Base_Directory)、[XDG Autostart](https://wiki.archlinux.org/title/XDG_Autostart)、[Uniform look for Qt and GTK applications](https://wiki.archlinux.org/title/Uniform_look_for_Qt_and_GTK_applications)、[Fonts](https://wiki.archlinux.org/title/Fonts)、[HiDPI](https://wiki.archlinux.org/title/HiDPI)

## XDG 目录：配置、数据、缓存各归各位

| 变量 | 默认值 | 放什么 | 备份价值 |
| --------------------- | ------------------------ | ------------------------------------ | ---------------------- |
| `XDG_CONFIG_HOME` | `~/.config` | 应用配置、主题、自启项 | 高（重装可恢复） |
| `XDG_DATA_HOME` | `~/.local/share` | 应用数据、图标、字体、密钥环 | 中（含不可再生数据） |
| `XDG_CACHE_HOME` | `~/.cache` | 可重建的缓存、缩略图 | 低（可删） |
| `XDG_STATE_HOME` | `~/.local/state` | 日志、会话状态、历史 | 低到中 |
| `XDG_RUNTIME_DIR` | `/run/user/<uid>` | 套接字、锁文件，登录期间有效 | 不备份 |

```bash
echo "$XDG_CONFIG_HOME $XDG_DATA_HOME $XDG_CACHE_HOME $XDG_STATE_HOME"
echo "$XDG_RUNTIME_DIR"
xdg-user-dir DESKTOP
```

本机 `xdg-user-dir DESKTOP` 返回 `/home/y2c/Desktop`，即使该目录不存在；`XDG_RUNTIME_DIR` 在 SSH 会话里也可能为空。**配置优先写 `~/.config`，不要把主题、字体塞进 `~/.local/share` 的随机子目录**；`~/.cache` 可以放心删，`~/.local/share` 要先看清内容。

## 自启动：桌面条目与用户级服务

桌面自启动读取两处：

- `/etc/xdg/autostart/*.desktop`：所有用户；
- `~/.config/autostart/*.desktop`：当前用户，同名会覆盖系统项。

一个最小自启项：

```ini
[Desktop Entry]
Type=Application
Name=MyHelper
Exec=/usr/local/bin/myhelper --daemon
Hidden=false
X-GNOME-Autostart-enabled=true
```

常见坑：`Hidden=true` 表示「显式禁用」，不是「隐藏图标」；`Exec` 用相对路径或依赖 shell 变量会失败；文件没有执行位不影响自启，但 `Exec` 指向的脚本必须有执行位。需要「登录即跑、可查状态、可重启」的长期进程，优先用用户级 systemd（第 63 章）：

```bash
systemctl --user enable --now myhelper
systemctl --user status myhelper
```

**桌面自启只在图形会话里执行，用户级服务随 `logind` 会话启停**；需要 `linger` 才能在未登录时运行，两者的适用场景不同。

## 主题：GTK 与 Qt 的统一

GTK 应用读 `~/.config/gtk-3.0/settings.ini`（GTK3）或 `gsettings`（GNOME 系）：

```ini
# ~/.config/gtk-3.0/settings.ini
[Settings]
gtk-theme-name = Adwaita-dark
gtk-icon-theme-name = Papirus-Dark
gtk-font-name = Noto Sans 11
gtk-cursor-theme-name = Adwaita
```

```bash
gsettings get org.gnome.desktop.interface gtk-theme
gsettings set org.gnome.desktop.interface gtk-theme 'Adwaita-dark'
gsettings set org.gnome.desktop.interface icon-theme 'Papirus-Dark'
```

Qt 应用不读 GTK 配置，需要平台主题插件：

```bash
sudo pacman -S qt6ct kvantum
export QT_QPA_PLATFORMTHEME=qt6ct # 写进 ~/.config/environment.d/ 或会话启动文件
```

- `qt6ct` 提供「跟随 GTK 风格」的配置界面，配置在 `~/.config/qt6ct/qt6ct.conf`。
- `Kvantum` 提供 SVG 主题引擎，适合想要完整 Qt 主题包的用户。
- Plasma 会话里 Qt 走 `kde` 平台主题，改 `kdeglobals` 或系统设置即可，不必再套 `qt6ct`。
- **环境变量必须在会话启动时注入**；只在当前 shell `export`，从启动器打开的应用读不到。

图标与光标：

```bash
ls ~/.local/share/icons/ /usr/share/icons/ | head
gtk-update-icon-cache ~/.local/share/icons/MyTheme
```

图标主题目录里必须有 `index.theme`；光标主题同样通过 `index.theme` 声明，放在 `~/.local/share/icons/default/` 可设为默认。`~/.icons` 是旧路径，仍被部分程序读取，但新配置一律用 `~/.local/share/icons`。

## 字体：安装、缓存与匹配

```bash
sudo pacman -S noto-fonts noto-fonts-cjk noto-fonts-emoji
fc-cache -fv
fc-match sans-serif
fc-match 'Noto Sans CJK SC'
fc-list :lang=zh | head -5
```

本机实际结果：`fc-match sans-serif` 返回 `NotoSans-Regular.ttf: "Noto Sans" "Regular"`；`fc-list :lang=zh` 列出 `Noto Sans CJK JP/TC/HK` 等条目；`fc-list` 总数为 2703。**字体装了不等于匹配对了**：`fc-match` 显示的实际文件才是应用会用的字体；中文环境要确认匹配结果里出现 CJK 字体，而不是某个不含中文的拉丁字体。

按用户覆盖匹配规则用 `~/.config/fontconfig/fonts.conf`，改完 `fc-cache -fv`；不要直接改 `/etc/fonts/` 下的系统文件。

## 缩放：X11 与 Wayland 的差别

X11 下缩放靠环境变量与工具包配合：

```bash
export GDK_SCALE=2 # GTK：整数倍
export GDK_DPI_SCALE=0.5 # 补偿字体过大
export QT_SCALE_FACTOR=1.5 # Qt：支持小数
```

- `GDK_SCALE` 只接受整数，混合 DPI 多屏在 X11 下很难完美；`QT_SCALE_FACTOR` 支持小数但可能模糊。
- Wayland 下由合成器按输出设置 scale，**不要再用 `GDK_SCALE`/`QT_SCALE_FACTOR` 叠加**，否则会二次缩放（第 84 章）。
- 只影响当前会话；持久化写进 `~/.config/environment.d/*.conf`（用户级 systemd 环境）或桌面会话的启动配置。

## 可复现实验：配置位置的证据

```bash
echo "$XDG_CONFIG_HOME $XDG_DATA_HOME $XDG_CACHE_HOME"
xdg-user-dir DESKTOP
ls ~/.config/autostart/ 2>&1
ls ~/.config/gtk-3.0/settings.ini 2>&1
gsettings get org.gnome.desktop.interface gtk-theme 2>&1
fc-match sans-serif
fc-list :lang=zh | wc -l
env | grep -E 'GTK|QT|GDK' || echo "当前 shell 无相关变量"
busctl --user list 2>/dev/null | grep -ci portal
```

**预期与解读**：`xdg-user-dir` 即使在无 GUI 时也能工作；`gsettings` 读取的是 dconf 数据库，不需要图形会话；`fc-match` 直接反映字体匹配；`env` 为空说明变量没在会话级注入，从启动器打开的应用同样读不到。

## 失败模式

| 现象 | 根因 | 处置 |
| ------------------------------ | ------------------------------------------ | ------------------------------------------------------ |
| Qt 应用不跟随 GTK 主题 | Qt 不读 GTK 配置 | 装 `qt6ct`/`kvantum`，设 `QT_QPA_PLATFORMTHEME` |
| 自启项不执行 | `Hidden=true`、`Exec` 路径错、无执行位 | 查 `~/.config/autostart` 与 `journalctl --user` |
| 换主题后图标缺失 | 新主题没装或缓存未更新 | 装图标包，`gtk-update-icon-cache` |
| 中文显示为方块 | 缺 CJK 字体或 `fc-match` 匹配错 | 装 `noto-fonts-cjk`，`fc-cache -fv` 后复核 |
| 界面过大/过小 | 同时设 `GDK_SCALE` 与 Wayland scale | 只保留一层缩放，Wayland 交给合成器 |
| 从启动器打开的应用没环境变量 | 只改了当前 shell | 写进 `environment.d` 或会话启动文件 |
| 光标主题不生效 | 缺 `index.theme` 或路径不在搜索目录 | 放到 `~/.local/share/icons/default/`，检查 `index.theme` |
| 配置在重装后全丢 | 配置写进了 `~/.cache` 或临时目录 | 迁回 `~/.config`/`~/.local/share` |

## 验证与回滚

```bash
gsettings get org.gnome.desktop.interface gtk-theme
gsettings get org.gnome.desktop.interface icon-theme
fc-match sans-serif
fc-match -f '%{file}\n' 'Noto Sans CJK SC'
ls -l ~/.config/autostart/
env | grep -E 'QT_QPA_PLATFORMTHEME|GDK_SCALE'
```

「配置值、匹配结果、自启项、环境变量」四者能解释绝大多数「看起来没生效」的问题。改主题后重启应用（不是重启系统）即可验证；GTK 主题变更通常立即生效，Qt 需要重开应用。

回滚：

```bash
gsettings reset org.gnome.desktop.interface gtk-theme
mv ~/.config/gtk-3.0/settings.ini /tmp/ # 先移走
unset QT_QPA_PLATFORMTHEME # 当前 shell；持久化还要删 environment.d 里的行
rm ~/.config/autostart/myhelper.desktop
```

删除配置前先备份到 `/tmp` 或版本库；主题与图标目录体积大，回滚时用包管理器重装对应主题包比手工恢复更可靠。

## 取舍边界

- **`~/.config` 覆盖 vs 系统 `/etc`**：个人偏好写用户目录；多用户统一策略才写 `/etc/xdg`，且要接受升级覆盖风险。
- **桌面自启 vs 用户级 systemd**：一次性 GUI 辅助程序用 autostart；需要状态、重启、日志的长期进程用 `--user` 服务。
- **GTK 原生主题 vs 第三方主题包**：原生主题随版本升级稳定；第三方主题好看但常在 GTK 版本升级后失效。
- **Qt 跟随 GTK vs 各自主题**：统一外观要装桥接（qt6ct/Kvantum），代价是多一层配置与兼容问题；不介意差异就各自用默认。
- **整数缩放 vs 小数缩放**：整数缩放清晰但布局偏大；小数缩放灵活但可能模糊，Wayland 下优先让合成器做。
- **字体全家桶 vs 按需安装**：`noto-fonts` 全量占空间但省事；精简安装要自己保证 `fc-match` 覆盖到中文、emoji 与等宽字体。

## 小结

- XDG 五目录：配置进 `~/.config`，数据进 `~/.local/share`，缓存可删，运行时目录不备份。
- 自启有两套：`~/.config/autostart` 的 `.desktop` 与 `systemctl --user`；后者可查状态、可重启。
- GTK 走 `settings.ini`/`gsettings`，Qt 走 `qt6ct`/`kvantum`/`kdeglobals`，统一外观需要桥接。
- 图标与光标主题必须有 `index.theme`，放 `~/.local/share/icons` 并在换主题后更新缓存。
- 字体装完要 `fc-cache -fv`，用 `fc-match` 验证实际匹配，不只数数量。
- X11 用 `GDK_SCALE`/`QT_SCALE_FACTOR`，Wayland 交给合成器，避免叠加缩放。

## 练习

1. 目录归位：列出你机器上 `~/.config`、`~/.local/share`、`~/.cache` 各三个子目录，判断哪些值得备份。
2. 自启对比：写一个 `~/.config/autostart` 条目与一个用户级 service，说明各自何时启动、如何查看状态。
3. 主题统一：查当前 `gtk-theme` 与 `icon-theme`，再打开一个 Qt 应用，判断它是否跟随；写出用 `qt6ct` 统一的步骤。
4. 字体匹配：`fc-match sans-serif`、`fc-match monospace`、`fc-match 'Noto Sans CJK SC'`，解释输出文件与「应用实际显示」的关系。
5. 缩放验证：在 X11 会话里设 `GDK_SCALE=2` 打开一个 GTK 应用，再在 Wayland 会话里对比，说明为什么后者不该再设。
6. 故障注入：把某个自启项的 `Hidden` 改为 `true`，验证它不再运行，再改回；记录判断依据。
