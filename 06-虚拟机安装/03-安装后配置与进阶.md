# 03 安装后配置与进阶

基础系统装好并不等于可用：locale、时区、主机名、用户、sudo、网络都还没配。本章在 chroot 中完成收尾，重启后逐项验证，最后给出一张进阶路线图，说明哪些内容本书只指方向、必须回到 Wiki 深入。

> 本章目标：能完成安装后配置，重启进入可登录、可联网、可 `sudo` 的系统，并知道下一步该学什么。
> 对应 Wiki：[General recommendations](https://wiki.archlinux.org/title/General_recommendations)｜[Network configuration](https://wiki.archlinux.org/title/Network_configuration)

## 3.1 基础系统配置

以下命令在 `arch-chroot /mnt` 后的 root shell 中执行，不需要 `sudo`；本节与 3.2 节都如此，重启后补做才加 `sudo`。先在 `/etc/locale.gen` 取消 `en_US.UTF-8 UTF-8` 与 `zh_CN.UTF-8 UTF-8` 的注释，再按顺序执行：

```bash
locale-gen
echo "LANG=en_US.UTF-8" > /etc/locale.conf
ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
hwclock --systohc
echo "arch-vm" > /etc/hostname
passwd
useradd -m -G wheel -s /bin/bash arch
passwd arch
pacman -S sudo vim
EDITOR=vim visudo
```

`locale-gen` 生成 locale 数据，`/etc/locale.conf` 决定登录后的语言环境。不要把 `LC_ALL` 写进 `locale.conf`，它会覆盖所有 `LC_*` 设置，导致排序和日期格式异常；中文 locale 还需要中文字体，留到桌面环境补。`/etc/localtime` 是指向时区数据库的符号链接，`hwclock --systohc` 把系统时间写入硬件时钟，默认按 UTC 处理。

同时检查 `/etc/hosts`，保证本机能解析自己的主机名：

```text
127.0.0.1   localhost
::1         localhost
127.0.1.1   arch-vm.localdomain arch-vm
```

`useradd` 的 `-m` 创建家目录，`-G wheel` 加入 `wheel` 组，`-s /bin/bash` 指定 shell。`visudo` 中取消这一行的注释，保存后语法会被自动检查：

```text
%wheel ALL=(ALL:ALL) ALL
```

网络由 NetworkManager 管理。chroot 中只能 `enable`（离线创建自启链接），不能 `start`，因为 PID 1 仍是 Live 环境：

```bash
pacman -S networkmanager
systemctl enable NetworkManager
```

重启后验证并连接无线网络：

```bash
nmcli device status
nmcli device wifi list
nmcli device wifi connect "SSID" password "密码"
ping -c 3 archlinux.org
```

## 3.2 镜像源、微码与基础工具

```bash
pacman -S reflector pacman-contrib
cp /etc/pacman.d/mirrorlist /etc/pacman.d/mirrorlist.bak
reflector --country China --age 12 --protocol https --sort rate \
  --save /etc/pacman.d/mirrorlist
pacman -Syyu
```

换源后用 `-Syy` 强制刷新数据库，再完整升级。`reflector` 生成的是静态列表，网络环境变化后要重新生成，细节见[镜像源配置](../01-环境准备/03-镜像源-配置与备份.md)。

按 CPU 厂商安装微码：

```bash
pacman -S intel-ucode    # Intel
pacman -S amd-ucode      # AMD
```

微码必须在 initramfs 之前加载。GRUB 重新执行 `grub-mkconfig -o /boot/grub/grub.cfg`，通常会自动加入微码镜像；systemd-boot 则在 entry 中把 `initrd /intel-ucode.img` 放在 `initramfs-linux.img` 之前。虚拟机中微码效果有限，但配置方法必须掌握，最后执行 `mkinitcpio -P`。

| 包                | 用途                       |
| ----------------- | -------------------------- |
| `base-devel`      | 编译 AUR 包所需工具链      |
| `git`             | 拉取 PKGBUILD 与源码       |
| `vim`             | 编辑配置，可换成其他编辑器 |
| `man-db`          | `man` 手册页               |
| `bash-completion` | 命令与路径补全             |

```bash
pacman -S --needed base-devel git vim man-db bash-completion
```

## 3.3 重启与验证

```bash
exit
umount -R /mnt
reboot
```

重启前在虚拟机设置中移除 ISO，避免又从 Live 环境启动。

| 检查项   | 命令                                             | 期望结果                         |
| -------- | ------------------------------------------------ | -------------------------------- |
| 引导模式 | `cat /sys/firmware/efi/fw_platform_size`         | `64`                             |
| 引导条目 | `efibootmgr -v` 或 `bootctl status`              | 有 Arch/GRUB 条目                |
| systemd  | `systemctl is-system-running`                    | `running`（`degraded` 需继续查） |
| 失败单元 | `systemctl --failed`                             | 列表为空                         |
| 网络     | `nmcli device status`、`ping -c 3 archlinux.org` | connected，能通外网              |
| sudo     | `sudo -v`、`id`                                  | 提权成功，用户在 `wheel` 组      |
| 时间     | `timedatectl`                                    | 时区正确，NTP 可用               |
| 磁盘     | `lsblk -f`、`findmnt /`、`findmnt /boot`         | 分区与挂载点正确                 |
| 日志     | `journalctl -p err -b`                           | 无持续性错误                     |

启动失败时用 Live ISO 挂载原系统并 chroot：

```bash
mount /dev/vda2 /mnt
mount /dev/vda1 /mnt/boot
arch-chroot /mnt
```

进入后按需修复 fstab、重装引导器或重新生成 initramfs。btrfs 使用子卷时挂载要加 `-o subvol=`，以 [Btrfs](https://wiki.archlinux.org/title/Btrfs#Mounting_subvolumes) 为准。完成后 `exit`、`umount -R /mnt`、重启。

## 3.4 进阶路线

以下主题本书只给方向和入口，不展开完整配置。每项都足以单独成章，且随版本变化较快，操作前以 Wiki 当前内容为准。

| 主题       | 先理解什么                                                                     | 入口                                                                                                                                             |
| ---------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 内核与模块 | `uname -r`、`lsmod`、`modprobe`、`/etc/modprobe.d/`、`mkinitcpio` 的 `MODULES` | [Kernel](https://wiki.archlinux.org/title/Kernel)、[Kernel module](https://wiki.archlinux.org/title/Kernel_module)                               |
| 磁盘加密   | LUKS 容器、`cryptsetup`、initramfs 的 `encrypt` hook、GRUB 对 LUKS2 的限制     | [dm-crypt](https://wiki.archlinux.org/title/Dm-crypt)、[System configuration](https://wiki.archlinux.org/title/Dm-crypt/System_configuration)    |
| btrfs 快照 | 子卷布局、`snapper`、快照与 `/boot` 的关系                                     | [Btrfs](https://wiki.archlinux.org/title/Btrfs)、[Snapper](https://wiki.archlinux.org/title/Snapper)                                             |
| 桌面环境   | Wayland/Xorg、显示管理器、显卡驱动                                             | [Desktop environment](https://wiki.archlinux.org/title/Desktop_environment)、[Display manager](https://wiki.archlinux.org/title/Display_manager) |
| 容器       | 镜像与命名空间、Docker/Podman、`systemd-nspawn`                                | [Docker](https://wiki.archlinux.org/title/Docker)、[Podman](https://wiki.archlinux.org/title/Podman)                                             |
| 网络安全   | 防火墙、SSH 密钥登录、最小权限                                                 | [Security](https://wiki.archlinux.org/title/Security)、[OpenSSH](https://wiki.archlinux.org/title/OpenSSH)                                       |

建议顺序：先弄懂内核与模块，再碰 LUKS 和 btrfs 快照，最后装桌面，避免排障变量成倍增加。

## 小结

- locale、时区、主机名、root 密码、普通用户、sudo、网络是安装后的最小配置集。
- chroot 中 `systemctl enable` 有效，`systemctl start` 不代表新系统已启动。
- 微码必须在 initramfs 之前加载，GRUB 与 systemd-boot 的配置方式不同。
- 内核、LUKS、btrfs、桌面、容器属于进阶内容，本书只给方向，以 Wiki 为准。

## 练习

1. 在 chroot 中完成最小配置，并记录每一步改动的文件。
2. 分别用 GRUB 和 systemd-boot 配置微码加载，比较菜单或 entry 的差异。
3. 重启后按验证清单检查，把输出整理成一份安装报告。
4. 故意改错 fstab 的根分区 UUID，观察启动报错，再用 Live ISO 修复。
